## What's New

This release delivers three receiver improvements and two developer tools.

### 1. DTMF decoder follows the D Live setting (RX-10)

RX setup enables the DTMF decoder and its interrupt only when `D Live` is on.
When disabled, the decoder remains off across VFO reconfiguration. DTMF
transmit features, including PTT-ID and DTMF-ID, are unchanged.

### 2. AGC state is restored reliably after spectrum use (RX-11)

RX setup now programs AGC from the requested state instead of relying on a cache
that could miss direct register changes made by the spectrum analyzer. Spectrum
listen mode also freezes and restores AGC as intended.

### 3. RX audio path is re-armed on every receive entry (RX-12)

The centralized `RADIO_SetAudioPath()` restores the BK4819 AF DAC before
unmuting the amplifier, with a 500 µs settling interval. This makes RX audio
initialization consistent after VFO changes and other features that alter chip
audio state, while sequencing mute/unmute to control pops.

The `tools/rx_probe_vfo.ps1` utility reads and audits per-VFO EEPROM records,
and can write corrections to a separate output image without modifying the
input dump. See
[`Documentation/VFO_RX_SILENCE_DIAGNOSTIC.md`](Documentation/VFO_RX_SILENCE_DIAGNOSTIC.md).

### 4. Local build helper repaired (tooling, not firmware)

`tools/build_k5.ps1` now derives the firmware version and feature toggles from the
Makefile, keeping the local build configuration aligned with the project settings.

- Build: `-Oz -Wall -Wextra -Werror`, LTO and `--gc-sections`; 0 warnings and 0 errors.
- ApeX build completed successfully. Flashable `.bin` size: 61,352 B, with 88 B free.

- Hardware behavior is not claimed as bench-verified by this release note.
